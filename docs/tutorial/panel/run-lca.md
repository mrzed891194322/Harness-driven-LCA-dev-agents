# 在面板里执行 LCA

1. 顶栏「模型设置」配置 Provider 和 API Key；在「项目状态」确认环境与 openLCA 就绪。
2. 「LCA 计划」→「新工作」：填写或上传计划，计划自动保存。点「去运行」。
3. 「运行详情」：工作流选 full-lca，选模型，点「开始运行」。节点表实时显示进度；需要时可停止，之后点「继续」。
4. 「结果浏览」查看报告和每个节点的审核结论。

修订已有结果：在「结果浏览」点「修改计划」（或「LCA 计划」→「修改工作」）写修订计划，
「去运行」后选 revise-lca。上一轮的产出会保存在 `artifacts/previous/`，在结果页「上一版」里查看。
