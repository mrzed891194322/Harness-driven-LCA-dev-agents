# 文档索引

本目录按用途分四块；现行架构以 `architecture/` 为准。过期文可放本机 `archive/`（不进 git）。

| 目录 | 用途 |
|------|------|
| [architecture/](architecture/) | 现行设计：布局、工作流、产物、交付主 agent、MCP、会话注入、GUI |
| [guide/](guide/) | 教程（`tutorial/`）与中文环境/适配说明（`lang_CN/`） |
| [ops/](ops/) | 运行中问题台账、serve/dev worktree、待办 |
| `archive/` | 过期文（本机保留，**不进 git**） |
| [assets/](assets/) | 图片等静态资源 |
