# 资料与证据来源

- 研究证据以本任务运行上下文的 `knowledge_sources` / `source_manifest` 和已绑定检索、查询工具为准，不访问未声明来源，不用网络或模型记忆静默补数据。计划与修订文件提供研究要求及用户假设，不自动证明其中数值是测量事实。
- 优先读取 `source_manifest`；核对磁盘时只对声明路径用 `rg --files --hidden --no-ignore <declared-path>`。不得由默认 rg/git status 的空结果推断资料缺失，不扫描未声明目录。
- 引用使用文件路径或文档 ID 加 `#定位`，如 `path/to/a.pdf#p3`、`path/to/a.md#L10-L20`。在 `source_locations` 引用原始依据；工具证据保留正式 artifact 引用。来源缺失、无法读取或检索失败如实记录，禁止编造定位。
- 在现有 Markdown 说明中区分原始事实、换算、估算、代理和用户假设；派生数值记录原值、公式、系数依据、单位及适用条件，不把生成的汇总当作独立原始来源。
- 资料冲突时列明相互矛盾的数值和位置、采用理由。计划可指定主情景与备选情景；不能静默挑选、平均或把用户选择写成已消除的事实冲突。无法消解的关键冲突按缺口处理。
- 01 仅读启动所需段落；02 起分段读取相关章节和表格，避免全量展开长文或 raw。临时提取文件可辅助阅读，但正式产物必须回链到可审查的原始定位。
