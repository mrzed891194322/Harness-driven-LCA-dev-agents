# 用户资料

- 用户参考资料与项目事实只存在 `harness/knowledge/`（扁平目录）。`workspace/inputs/` 仅含 `plan.md` 与 `revise.md`，是工作流结构化输入，不是证据检索域。不要到 `workspace/inputs/references/` 或已删除的 `user_ref` 路径查找副本。
- 需要数值、物料、运输、地域、工艺说明或清单时，直接读取该目录中的文件。按文件名、计划中的路径或简称匹配；匹配到后记录路径和章节/行号。
- 目录为空或找不到引用文件时，记为未解决项或按第 01 阶段处理，不得编造数据。
- 证据来源类型：用户文件用 `user-file`；方法条款用 `standard`。
