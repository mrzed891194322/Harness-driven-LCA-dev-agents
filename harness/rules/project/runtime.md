# 运行环境与离线处理

- Python 使用项目的 `uv run` 环境；不使用系统 Python、不另建环境、不硬编码 `.venv/` 路径。依赖和工具配置由项目管理，任务不自行安装依赖或修改锁文件。
- 允许在 `workspace/tmp/` 编写离线脚本，用于读取已声明资料、表格提取、单位换算、生成本阶段获准产物和独立核算。只使用现有依赖，读取和写入遵守当前角色边界。
- 离线脚本不得联网补充资料，不得直接连接 openLCA、调用 IPC/HTTP、导入正式工具的内部函数来绕过 MCP，或修改权威校验记录。
- 离线复算只能作为推导和审查证据，不能冒充 openLCA 计算、工具 raw 或机器检查 passed。记录输入定位、公式、单位和结果，使正式产物无需保留临时会话也能复核。
- 硬工具交付（导入、LCIA 类别总量、Monte Carlo 数值分布、必须来自工具的过程贡献数值表等）无法完成时，明确报告能力缺口及受影响的要求，停止相关阶段；不编造结果或静默省略。解释类主张缺专用工具时，按阶段契约 `llm_inferred` 标注出处后继续，禁止静默降级或伪装成 `tool_backed`。不得把「用户未在 plan 写允许 fallback」当成失败理由。
