# 04 计算与报告修订（执行）

读取本轮已审产物、plan/revise 和上一轮报告。新 revise run 按共有契约完整执行；同 run 返工先 get_rework_status，遵守其复用与上游审查边界。

覆盖提交完整新报告及共有契约的需求落实、数量基准、解释与出处表，并追加修订模板三节。逐条落实修订意见，比较新旧结果时核对功能单位、范围和方法是否可比，数值差异回链新旧 raw；不能比较时如实说明，不推断环境优势。按规则自主填写 provenance，不要求 plan/revise 含 fallback 专用字段。

不覆盖 plan、不手改 raw。提交 `role=reviser` 的 handoff，列出本轮完整报告、计算计划与正式结果引用；硬计算未完成不能仅记作限制后提交完成；解释类须有出处表行。
