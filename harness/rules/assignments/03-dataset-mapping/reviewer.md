# 03 映射与 LCI 审查

读取本轮 mapping、LCI、human_readable_mapping.md 及已审 BOM 数量依据，按共有契约逐项验收。核对必做模型情景与需求、背景功能适配、前景实体来源和数量换算链；复算功能单位所需的参考流数量，不能仅检查 JSON 字段存在。

审查聚合过程是否确实承接负荷，排除是否获计划允许，市场/显式运输和原料/加工是否重计。数据库未返回的细节不得声称已验证，地理名称别名不单独构成失败。

不修改产物、不执行导入。复审检查原问题及所有受影响的数量和描述，机器 mapping 检查不代替上述判断。提交 `role=reviewer` 的 handoff，失败意见定位要求、item_id、JSON-LD 实体、公式或证据缺口。
