# 计划核对（启动门禁）

读取 `<plan>` 和计划点名的参考资料（`harness/knowledge/inputs/` 下），写一份中文核对清单 `intake.md`：

1. 研究对象与目的、功能单位（功能描述、数值、单位）、系统边界、截断规则、多产出/分配、预期应用。
2. 计划点名的资料与实际文件的对应关系（缺失则写明）。
3. 必做情景、敏感性分析、指标、交付要求、禁止替代条件；区分必做与可选。
4. 硬工具缺口：只有措辞只能理解为需要当前工具没有的计算输出（如 Monte Carlo 分布、openLCA 过程贡献数值表）才算缺口；解释类要求（热点、主要贡献的叙述）不算。

缺少关键事实、模板占位、资料缺失或存在硬工具缺口时，以 `status=stop` 提交并在 summary 中写明。本节点不查库、不写 BOM。
