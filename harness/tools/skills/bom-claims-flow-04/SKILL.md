# BOM 数量抽取 · 04 executor

内容取舍统一按已注入的 `BOM extraction 04 · 共同抽取口径`；本技能只规定执行顺序。

1. **定题**：读文前，只依 `<plan>` 将「对象×所问指标」写到注入给出的 checklist 路径，形状为 `{"items":["…"]}`。同材料、同路径的连续工序被题面作为一个总量询问时列一项；明确分问才分项。之后不为凑 claims 数改写清单。
2. **找证据**：从本次提供的 knowledge 逐项查找，阅读完整相关段落和表格。核对行列、单位、倍率、统计口径、端点与总分关系；搜索摘要不能替代原文。每项记清直接答案的来源和条件，既找遗漏也查候选是否题外。
3. **写产物**：按共同口径整理独立答案、合并重复表达，写入注入指定的 claims 交付路径。共用条款覆盖多项时在同条 text 中保留各项完整称呼与适用依据，不复制数值来修标签。保持现有 schema，不把阅读笔记或清单塞进 claims。
4. **自查并结束**：从清单逐项核对有没有漏答案，再从每条 claim 回查来源和交付必要性。结束说明仅列来源覆盖、缺证/冲突、计算及合并/排除理由。不要调用 check MCP 或 submit；审核和交卷由另外两角色完成。
5. **返工**：读取 issues，修复指定问题及其直接影响的证据/条件，保持无关条目不变；对受影响清单项重新核对。若要求与原文冲突，说明来源和无法执行的原因，不猜改、不删真答案来通过检查。
