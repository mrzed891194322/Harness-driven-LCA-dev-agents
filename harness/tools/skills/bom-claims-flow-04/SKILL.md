# BOM 数量抽取 · 04 executor

按序执行。单位/区间/不估算口径以挂载的 PCFBench 官方 rule 为准。

1. **题面契约（读文前）**：只依题面把清单写入 user 注入里给出的 checklist 路径：`{"items":["对象×所问指标", ...]}`。读文后再写 claims；清单不进 claims schema。
2. **定清单**：`N=len(items)` 是**核对覆盖**用的清单长度（对象×指标条数），**不是** claims 条数配额。题面把同材料/同路径连续工序用单数量词和 and（含 respectively）问成一项时，清单只列 1 项。示例对象不自动展开为对象×工艺×阶段的笛卡尔组合；明确要求逐对象、逐条件回答时才展开，点名对象仍须核对。读文后不反扩清单，不向没有依据的组合外推数值，也不把共用条款复制成逐对象 claims。
3. **读原文并抽取**：按清单在 `harness/knowledge/inputs/` 定位，读完整段落、表头、行列标签和脚注确认适用条件，再写 `workspace/runs/_run/artifacts/bom/claims.json`。搜索命中或邻近数字不是行选择依据；先核对对象、指标、时间尺度和统计口径，区分 annual 与 average annual、近似叙述与明确表值。
4. **对象×指标**：只答题面所问；不因同文纳入题外对象，也不无据排除对照/同行对象。
5. **区间**：范围用**中点**一条；题面问单值且原文有作者代表值时用代表值。
6. **交付必要性**：逐条按下文核对，再跨清单项检查共用条款是否被复制；“原文有据”还须满足“直接回答主问且增加独立的所问信息”。同槽独立答案可多条，**勿**为凑 `claims 条数 = N` 合并或删条。
7. **`unit` 字段**：写原文里该数值旁的**短单位 token，与原文一致**（如原文 `1.32lbs` → `unit` 用 `lbs`，**勿** silent 改成 `lb` 或其它单复数/别名）。「短符号」指原文短写法，不是强行单数化或 scorer 表归一。
8. **交付**：无依据交 `claims: []`。结束说明简列本轮合并/移除的 claim ID、保留条及原文关系；未合并的相似条说明独立依据，供 reviewer 复核，不加进 claims schema。写完 **勿** 调用 `mcp__bom_claims_check__check_claims`（核对由 reviewer + MCP）。有 `<rework>` 时只改所列问题。

## 交付必要性与合并边界

- **主问与主条款（canonical）**：先找直接回答所问对象、指标和条件的条款/表行；主条款由题面和原文适用范围确定，不由出现顺序、最大/最小值或预期条数决定。主问已有覆盖时，原文明示“可选/替代”的工艺默认不另列；题面要求替代方案、全量工艺或比较，或替代方案是唯一可答依据时仍保留。不能仅凭脚注位置或出现 alternative 一词删条。
- **独立多值**：不同来源估计、均值/标杆、实际采用的年度处理量、实验水平、零值对照，只要直接答题且原文有据就保留；不能因为已有一个主值就删其它口径。题面明确限定某一口径时，勿拿相邻行或近似描述代替。
- **共用条款的重复表达（包括跨 temper）**：先按“来源条款＋实际所问对象/工艺＋阶段＋指标＋统计口径”核对候选组，再比较数值，不能只在同一 `item_id` 内去重。题面并列点名多个 temper/形态，不等于要求把同一条款抄成多份；同一工艺阶段的同温度若仅因共用条款适用于多个 temper、产品形态或时间条件而重复，合为一条，`text` 分别列明原文支持的 temper、形态与各自时间条件，`evidence` 保留温度条款与适用范围依据。**不同温度分别保留**，有据的形态分支不因已有主值就删除。同操作序列不自动等于所有温度、时间、锻件条件均相同；不把某形态/temper 的条件外推给其它对象。明确要求逐条件独立记录，或实际来自不同对象、来源、试验、阶段、统计口径时保留区分，禁止全局按 `value+unit` 去重。
- **覆盖标签不靠复制数值**：共用条款确有依据覆盖多个 checklist 项时，在同一 claim 的 `item_id` 或 `text` 中逐项保留这些清单项的完整原文称呼，并写清共同适用范围；不要只写自造缩写 slug，也不要为每项复制一条同值 claim。清单仍逐项核对，不为合并而改写/删减已定清单。只有原文支持的项可以标入；不靠堆标签掩盖缺证。标签匹配返工只修准确的覆盖表述与证据，不新增数值副本。
- **旁述/nominal 变体**：回读完整论述，分清句子是在规定所问工艺，还是借已有工艺讨论强度、耐蚀性、敏感性或偏差等未问性能。主工艺已有直接条款覆盖，候选仅作性能讨论的背景条件、未给出独立适用工艺时，不另交数值；在结束说明记录原句用途与已覆盖条款。不同数字、nominal 标签、距离远近都不能单独证明独立性或冗余；明确提供独立适用工艺且直接答题时保留。**禁止把完整的性能讨论截成“时间 at 温度”短片段后认定为新工艺**；也不把近似温度强改成主条款温度。
- **同一测量的双单位**：原文明示同一对象、条件和测量的主值及括号换算值，且题面允许两单位任选时，交一个数值 claim，另一表达保留在 `text/evidence`，不当作独立测量或替代工艺。优先取直接答题的主表/规格字段的原文数值与单位；无主表时取正文主表达。题面只指定某一单位时选原文已有的对应表达；明确要求两种表达时遵从题面。不得自行换算、按 scorer 偏好改单位，或仅因数值大致可换算就合并不同来源/条件的测量；`lbs` 等原文短 token 原样保留。
- **数值与单位同源配对**：表值从该表的行列标题/脚注取单位，不从另一图轴或邻近段落借单位后缀。年度实际施用量、跨年均值、年均速率分别核对；保留题面适用的年度值、零值对照及独立均值，均值的时间范围写进 `text`，不能因求了多年平均就擅加 `/year`。正文复述同一表值时以直接答题的表行口径为依据，保留原文表达，不改成统一单位。
- **可加总分项**：同一清单项、同单位同口径、不重叠且可清晰相加的分项，只交题面所问总和，不另交未问分项；已有总量时不重复交组成项。独立统计值或实际处理水平不能因数值巧合可相加而合并；禁止跨指标乘除。
- **落盘**：不交题外、无依据、重复或 `value=null` 的数值条；每条尽量含 `claim_id`、准确的 `text`、`item_id`/`field` 及原文 `evidence`。改标签不能使不适用的数值变得适用。不设固定 claims 上限，不猜金标或用金标条数裁条。

交付前对每个相似候选组给出可复核结论：**独立保留 / 共用条款合并 / 同测量双单位合并 / 旁述不另交**。合并前后逐项检查温度分支、适用范围、时间和单位是否仍完整；若无法证明重复则保留并说明疑点，不能按期望条数裁剪。
