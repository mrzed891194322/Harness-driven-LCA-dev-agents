# 单位：只抄不译 / 不换算

- `unit` **照抄原文完整短语**：勿翻译、勿缩短（勿丢 `of X` / `glass` / `per kg …` / `nre` 等修饰）。
- **禁止换算**：勿 MJ↔kWh、lbs↔kg 等；原文写什么单位就交什么。
- 同一物料同一量：**只留一条** `(value, unit)`；原文并列双单位时只留主写那一档，勿再为换算结果另建 claim。
- `lbm` 与 `lb` 勿混写；短符号可用，但不要砍掉原文修饰。
- 数值区间（a–b）：拆成两端点两条；`value` 必须是数。
- 交付仍写原文单位；不要为对齐 scorer 擅自改写成别的符号族。
