# 读文档窗口

- 范围：`harness/knowledge/inputs/`（评测给法：`reference.md` = `document_text`）。
- 步骤：`ls` → `grep`（关键词 / 表头 / 单位）定位行号 → `read` 带 **`offset` / `limit`** 只取证据窗口。
- **禁止**对同一长文反复无参整文件 `read`；已读段落用 `grep` 回查。
- 大文件：`grep` → 命中行两侧小窗 → 不够再扩；多处证据多次小窗，勿一次读整份。
- `reference.md` 与同源 `*.pdf.txt` / `*.md` 重叠时：**只深读一份**（优先纯文本）。
- 引用写文件名与位置（行号或小节）；数值必须能回链窗口内原文。
- 定位只盯题面所问；同表邻居 / 扫参端点 / 分解项不要顺手纳入候选。
