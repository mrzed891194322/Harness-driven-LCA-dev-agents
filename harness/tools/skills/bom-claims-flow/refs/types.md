# 可交类型 / 黑名单 / 短防多报

## 可交

- 题面要的 **物料量 / 能量 / 占比** 等：`value`（数）+ `unit`（原文单位短语）。
- 材料与能量量纲（`kg`、`kg/ha`、`MJ/kg`、`kWh/kg`、`%`、`g/g`…）**不是**黑名单，勿因「宁漏」删掉。

## 黑名单（仅确认误伤项；题面未问时不交）

- 工时 / 时长：`h`、`hr`、`hour(s)`（题面未问工时）。
- 温度：`°C`、`°F`（题面未问温度）。

除此以外**不要**扩大黑名单（勿把压力、转速、材料能量量纲一刀切掉）。

## 短防多报（压 B2）

- **只交题面点名的量**；同表邻居行、扫参端点、未问的分解子项、无关 `%` —— 题面没点名就不要交。
- 初稿若顺手抄了整表：自检时删邻居/端点，**保留**题面所问的那几条（含同段精确量）。
- 多报与漏报都有害；本档用「短防多报」压堆表，**不用**弃权/清空来压多报。
