# 可交类型 / 黑名单 / 证据关系局部删

## 可交

- 题面要的 **物料量 / 能量 / 占比** 等：`value`（数）+ `unit`（**produce 短符号**，见 `units.md`）。
- 材料与能量量纲（`kg`、`kg/ha`、`MJ/kg`、`kWh/kg`、`%`、`g/g`…）**不是**黑名单，勿因「宁漏」删掉。

## 黑名单（仅确认误伤项；题面未问时不交）

- 工时 / 时长：`h`、`hr`、`hour(s)`（题面未问工时）。
- 温度：`°C`、`°F`（题面未问温度）。

除此以外**不要**扩大黑名单（勿把压力、转速、材料能量量纲一刀切掉）。

## 证据关系局部删（压 B2）

- 多报时**按证据关系局部删**：只删与题面所问**无证据关联**的条目；**不要**整卷清空，也**不要**用「题面没点名就一律砍」的短防多报口径。
- 判断看 claim 的原文证据是否支撑「所问」：证据就是题面所问量（含同段精确量、同证据链）→ **保留**；仅同表共现、证据答的是邻居行/扫参端点/未问分解子项/无关 `%` → **删该条**。
- 多报与漏报都有害；本档用「证据关系局部删」压堆表，**不用**弃权/清空来压多报。
