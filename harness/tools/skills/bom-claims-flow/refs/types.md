# 可交类型 / 黑名单 / 短防多报 / 题意锚定

## 可交

- 题面要的 **物料量 / 能量 / 占比** 等：`value`（数）+ `unit`（**produce 短符号**，见 `units.md`）。
- 材料与能量量纲（`kg`、`kg/ha`、`MJ/kg`、`kWh/kg`、`%`、`g/g`…）**不是**黑名单，勿因「宁漏」删掉。

## 黑名单（仅确认误伤项；题面未问时不交）

- 工时 / 时长：`h`、`hr`、`hour(s)`（题面未问工时）。
- 温度：`°C`、`°F`（题面未问温度）。

除此以外**不要**扩大黑名单（勿把压力、转速、材料能量量纲一刀切掉）。

## 短防多报（压 B2）

- **只交题面点名的量**；同表邻居行、扫参端点、未问的分解子项、无关 `%` —— 题面没点名就不要交。
- 初稿若顺手抄了整表：自检时删邻居/端点，**保留**题面所问的那几条（含同段精确量）。
- 多报与漏报都有害；本档用「短防多报」压堆表，**不用**弃权/清空来压多报。

## 题意锚定（压 B1）

- **先锚定再取值**：读题面 / plan，写下所问的 **对象**（哪个物料 / 能源 / 组分）、**量纲**（质量、能量、占比…）与 **范围**（哪一阶段、哪一功能单位）；只为这个锚找证据。
- **图例 / 表头绑定**：图表、饼图、分组表按 legend 或行列名词对齐题面对象；题面问的类别对应哪一档就交哪一档，**不要**交它的互补项、合计或相邻类别（除非题面明确要）。
- **符号 / 形态一致**：`value` 与证据中的数字逐位一致，含正负号（损失率、净排放等负值照原文写 `-`）、小数位与百分数形态；勿自行取绝对值或换算。
- 锚不清时：交与题面对象**最直接对应**的那条，并在 evidence 引原文；**不要**因此弃权或清空。
