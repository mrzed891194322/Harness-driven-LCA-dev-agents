# 可交类型 / 黑名单（压多报）

## 可交

- 题面明确要的 **物料量 / 能量 / 占比** 等数量声明：`value`（数）+ `unit`（原文单位短语）。
- 题面要上下界 / 一组工艺时，只交题面点名的那几条。

## 黑名单（默认不交）

- 工时 / 时长：`h`、`hr`、`hour(s)`、`min`、`s`（题面未问工时时）。
- 温度：`°C`、`C`、`K`、`°F`（题面未问温度时）。
- 同表邻居行、扫参端点、分解子项、无关百分比——题面没点名就删。
- 其它非物料 / 非能量 / 非题面所问的过程参数（压力、转速等），除非题面点名。

## 原则

- 金标 = 只答所问；多报与漏报同等有害，本档优先压多报。
- 吃不准是否题面所要 → **不交**（宁漏勿堆）。
