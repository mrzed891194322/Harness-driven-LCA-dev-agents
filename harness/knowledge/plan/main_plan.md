# 德国销售点 PET 水瓶 LCA 执行计划

> 用户只需明确研究对象、目的、范围、参考资料、openLCA 数据库与 LCIA 方法；
> 其余信息由 Agent 按项目规范从资料和活动数据库中解析。

## 1. 研究目的与范围定义

- **研究对象**：比较三种供应路线下在德国销售点交付的 1 L PET 静水瓶：德国本地生产、使用中国粒料并经铁路运输至土耳其生产、使用中国粒料并主要经海运运输至土耳其生产。
- **研究目的**：比较三个情景的环境影响及主要贡献过程，并验证 `whole-lca` 端到端工作流。结果仅用于内部教学和开发测试，不用于公开比较声明或现实产品环境绩效声明。
- **功能单位 (FU)**：在德国销售点交付 1,000 个装有 1 L 静水、带 HDPE 瓶盖和 PP 标签的 PET 瓶。
- **生命周期阶段**：Cradle-to-Point-of-Sale，包括原料背景供应链、瓶及组件生产、灌装和运输至德国销售点；不包括消费者使用、回收和最终处置。
- **质量/能量截断比例**：不采用自动截断；纳入参考资料明确给出的全部物料、水和运输。资料未提供的生产能耗、辅助材料和损耗不进入主模型，并作为研究限制报告。
- **多产出分配**：前景过程无共同产品，不实施额外分配；背景过程沿用指定数据库的 system model。
